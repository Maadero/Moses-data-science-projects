Research Project: Imbalanced Classification for Computer-Aided Breast Cancer Diagnosis (Machine Learning based) - Python
•
Developed machine learning models to address class imbalance in breast cancer diagnosis, improving predictive performance for minority-class (malignant) cases.
•
Employed data-level approaches ( undersampling- Instance Hardness Threshold, Cluster Centroids, oversampling- SVM SMOTE, Random Oversampling with Smoothing, and hybrid methods- SMOTE + Instance Hardness Threshold, SMOTE + Neighbourhood Cleaning Rule), ensemble approaches (RAMOBoost, AdaCost), and algorithmic approaches (Weighted SVM, Weighted ANN).
